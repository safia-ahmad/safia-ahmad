# About Me

```text
Building intelligent software that bridges cutting-edge AI research
with production-ready engineering.
```

I am a **Computer Science undergraduate at Aligarh Muslim University** passionate about designing intelligent systems powered by **Machine Learning, Large Language Models, Retrieval-Augmented Generation (RAG), and scalable backend engineering**.

My work focuses on transforming research ideas into reliable, deployable applications. I enjoy working across the complete AI development lifecycle—from data preprocessing and model development to API deployment and system optimization.

During my journey, I have built production-style RAG systems, fine-tuned large language models using LoRA, developed FastAPI services, and worked on research involving Physics-Informed Neural Networks. I enjoy solving practical problems while continuously learning modern AI technologies and software engineering practices.
